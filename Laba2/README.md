# Задание 2. Вариант 2. Иерархия классов «Летательные средства»

Avalonia-приложение, демонстрирующее работу иерархии классов (базовый класс и два наследника) с использованием паттерна MVVM, событий и абстрактных методов.

---

## Структура проекта

```
AviationApp/
├── AviationApp.csproj
├── App.axaml / App.axaml.cs          # Точка входа приложения
├── Models/
│   └── FlyingVehicle.cs               # Базовый класс и наследники (отдельный модуль)
├── ViewModels/
│   ├── ViewModelBase.cs
│   └── MainWindowViewModel.cs          # ViewModel главного окна
└── Views/
    └── MainWindow.axaml / .axaml.cs    # Представление (UI)
```

---

## Иерархия классов

Файл: `Models/FlyingVehicle.cs`

### Базовый класс `FlyingVehicle` (абстрактный)

| Свойство    | Тип      | Описание                          |
|-------------|----------|-----------------------------------|
| `Altitude`  | `double` | Высота над землей в метрах        |
| `Name`      | `string` | Название летательного средства    |
| `IsFlying`  | `bool`   | Находится ли в воздухе            |

| Метод       | Описание                          |
|-------------|-----------------------------------|
| `TakeOff()` | Абстрактный метод взлета (возвращает bool) |
| `Land()`    | Абстрактный метод посадки (возвращает bool) |

| Событие              | Описание                          |
|----------------------|-----------------------------------|
| `TookOff`            | Срабатывает при взлете            |
| `Landed`             | Срабатывает при посадке           |
| `AltitudeChanged`    | Срабатывает при изменении высоты  |

---

### Класс-наследник `Airplane` (самолет)

| Свойство        | Тип      | Описание                          |
|-----------------|----------|-----------------------------------|
| `RunwayLength`  | `double` | Длина взлетной полосы в метрах    |

Особенности:
- Для взлета требуется длина полосы не менее 500 м
- Для посадки требуется длина полосы не менее 400 м
- При взлете набирает высоту 1000 м

---

### Класс-наследник `Helicopter` (вертолет)

Особенности:
- Не требует взлетной полосы (вертикальный взлет/посадка)
- При взлете набирает высоту 500 м

---

## ViewModel

Файл: `ViewModels/MainWindowViewModel.cs`

- `MainWindowViewModel` наследует `ViewModelBase` и содержит всю логику управления:
  - Коллекция созданных объектов
  - Выбранный объект
  - Свойства для привязки данных (название, тип, высота, статус, цвет)
  - Команды для создания, удаления, взлета, посадки и очистки журнала

---

## Пользовательский интерфейс

Окно приложения содержит три основные секции:

### 1. Панель создания объектов
- Выбор типа: самолет или вертолет (RadioButton)
- Поле ввода названия
- Поле длины взлетной полосы (только для самолета)
- Кнопка "СОЗДАТЬ"

### 2. Панель управления выбранным объектом
- Список созданных объектов с отображением названия и высоты
- Информация о выбранном объекте:
  - Название
  - Тип (самолет/вертолет)
  - Текущая высота
  - Статус (В ПОЛЕТЕ / НА ЗЕМЛЕ)
- Кнопки "ВЗЛЕТ" и "ПОСАДКА" (активны в зависимости от состояния)

### 3. Журнал событий
- Отображение всех действий:
  - Создание объектов
  - Взлет и посадка
  - Изменение высоты
  - Удаление объектов
- Автоматическая прокрутка
- Кнопка "Очистить" для очистки журнала
- Статусная строка с текущим состоянием
