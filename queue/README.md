# Задание 1. Вариант 2. Класс «Очередь»

Avalonia-приложение, демонстрирующее работу обобщенного класса `Queue<T>` (очередь) с использованием паттерна MVVM.

---

## Структура проекта

```
queue/
├── Laba2.csproj
├── App.axaml / App.axaml.cs          # Точка входа приложения
├── Models/
│   └── Queue.cs                       # Класс очереди (обобщенный, отдельный модуль)
├── ViewModels/
│   ├── ViewModelBase.cs
│   └── MainWindowViewModel.cs          # ViewModel главного окна
└── Views/
    └── MainWindow.axaml / .axaml.cs    # Представление (UI)
```

---

## Класс `Queue<T>`

Файл: `Models/Queue.cs`

### Свойства

| Свойство    | Тип      | Описание                          |
|-------------|----------|-----------------------------------|
| `CurrentItem` | `T`    | Текущий элемент (первый в очереди) |
| `Count`     | `int`    | Количество элементов в очереди    |
| `IsEmpty`   | `bool`   | Признак пустоты очереди           |

### Методы

| Метод       | Описание                          |
|-------------|-----------------------------------|
| `Enqueue(T item)` | Добавляет элемент в конец очереди |
| `Dequeue()` | Удаляет и возвращает элемент из начала очереди |
| `Clear()`   | Очищает очередь                   |
| `GetAllItems()` | Возвращает все элементы для отображения |

---

## Пользовательский интерфейс

Окно приложения содержит:

1. **Информационная панель** — отображение текущего элемента, количества элементов и состояния очереди
2. **Панель добавления** — поле ввода и кнопка "Добавить"
3. **Список элементов** — все элементы очереди с автоматической прокруткой
4. **Панель управления** — кнопки "Извлечь элемент" и "Очистить очередь"
5. **Статусная строка** — отображение результатов операций
