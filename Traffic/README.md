# Симулятор пешеходного перехода (Traffic)

Оконное приложение на **Avalonia** (MVVM), моделирующее работу одного/нескольких пешеходных переходов:
по “большой дороге” движутся машины, а пешеходы идут через зебру в зависимости от фазы светофора.  
Иногда (с заданной вероятностью) происходит **ДТП столкновения** машины с пешеходом на переходе, после чего приезжает **аварийная служба**.

## Что реализовано

1. **Сценарии/процесс**
   - Основной процесс: работа светофора и движение транспорта/пешеходов.
   - Событие: ДТП (столкновение машины и пешехода) с вероятностью.
   - Событие: прибытие аварийной службы (после чего движение продолжается).

2. **Делегаты/события**
   - `TrafficLight.GreenForPedestrians` / `TrafficLight.RedForPedestrians`
   - `CrosswalkModel.EmergencyOccured` (ДТП)
   - `CrosswalkModel.EmergencyArrived` (служба прибыла)

3. **Многопоточность**
   - Симуляция запускается в фоне (`Task`) и диспатчится в UI-поток через `Dispatcher.UIThread.Post`.
   - Канцелляция потока симуляции — через `CancellationTokenSource`.

4. **Рефлексия**
   - В `CrosswalkModel` создаётся реализация `IEmergencyService` через рефлексию:
     `Activator.CreateInstance(...)` по найденному типу.

5. **Динамическая визуализация**
   - На `Canvas` рисуются и двигаются:
     - машины (`Cars`)
     - пешеходы (`Pedestrians`)
     - аварийный автомобиль (`EmergencyCars`)
   - Визуализация меняется “на лету” во время симуляции.

6. **Несколько моделей на форме**
   - Пользователь может добавить несколько переходов (кнопка **«Добавить переход»**).
   - Каждый переход — отдельный `CrosswalkModel` + `CrosswalkViewModel`, размещается в `ItemsControl`.

7. **MVVM / структура**
   - `ViewModels`: `MainWindowViewModel`, `CrosswalkViewModel`
   - `Models`: доменная логика (`CrosswalkModel`, `Car`, `Pedestrian`, `TrafficLight`, `EmergencyService`, `IEmergencyService`)


## Как работает симуляция

1. Нажмите **«Добавить переход»** — появляется новый переход со своими машинами и пешеходами.
2. Внутри `CrosswalkModel` работает цикл фаз светофора:
   - когда **красный для пешеходов** — двигаются/едут машины (в рамках логики остановки перед переходом);
   - когда **зелёный для пешеходов** — машины останавливаются перед зеброй, а пешеходы идут.
3. Во время **зелёного для пешеходов** с вероятностью `EmergencyProbability` происходит ДТП:
   - выбирается пешеход, который сейчас “идёт через зебру”,
   - выбирается ближайшая машина у зоны перехода,
   - обе сущности переводятся в координаты столкновения,
   - вызывается `EmergencyOccured` и запускается `IEmergencyService`.
4. Аварийная служба создаёт/запускает аварийную машину (`EmergencyCars`).
5. После прибытия аварийной машины:
   - ДТП-участники сбрасываются,
   - вызывается `EmergencyArrived`,
   - обычная симуляция продолжается.

## Основные классы

- `Car` — модель машины (позиции `PositionX/PositionY`, скорость, флаги участия в аварии и спец-режима).
- `Pedestrian` — модель пешехода (аналогично: `PositionX/PositionY`, скорость, флаги).
- `TrafficLight` — светофор и события изменения фазы.
- `CrosswalkModel` — центральная модель перехода (фазы, движение, ДТП, запуск аварийной службы).
- `IEmergencyService` — интерфейс аварийной службы.
- `EmergencyService` — реализация аварийной службы (создаёт аварийную машину).
- `CrosswalkViewModel` — запускает симуляцию и обновляет UI-тексты/флаги.
- `MainWindowViewModel` — управляет списком переходов и командой добавления.
